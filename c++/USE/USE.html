Hi

This is the usage guid for the engine

Oh, and the whole system is in metric, 1.0000 in an obj mean 1 meter(this might change in the future)

First, u want to go up to projects >> new project to create a project

without this step u won't be able to do anything

Now u can see sim. specs

This will be later important, but for now leave it as it is

Now you have to choose open... from the tool bar's project menu

The wavefront obj file strictly has to be ccw, or you'll have problems

But don't worry, most apllications today default to ccw, like blender, freecad, etc

I recommend chosing the already given cube since it's easy to handle

Now select the desired project, u want to import ur obj into

Important side note: you can't have two or more objects with the same name in one project, I already wanted to fix this, but I ran out of time

btw, u can actually double click the project u want

'cause I had time for the important things, right? ;)

Now u want to click on Simulate and choose setup

Now, you need to pick the project u want to simulate

And give it a duration and detailedness(tick amout)

Now, if you click to the side for a moment, the bottom ray adder will show up

Why u have to click to the side? Because this is the way of Imgui

Fill in the fields with ur desired numbers

The rays here have starting and ending points, the force expressed is in newtons,

and with the single tick checkbox u can toggle how the ray's activation time should be interpreted

Now click on add to current sim, not cast sim

Don't get scared when the fields of the ray get nullified. The previous ray got saved, and u can input the next one!

After, and only after u added ur last ray should u click on cast simulation, as it finalizes the sim

Now the whole sim field gets nullified, so u can just close the whole setup window with the x in the top right corner

Before u run sim, u should know, that, if I haven't made it obvious enough in the readme,

that there is a heisenbug, that I couldn't fix, and because of that only rays along the y axis work

I'll patch this asap, I just want to rest for a week

Secondly, u can't rerun, nor edit(unless u edit the json by hand) sim's yet, so if u close the sim, u'll have to delete the sim.json in the

cached/project1_currentdate_randomnumbetween1and1million/simulations/sim.json

there are some examples, that I have submitted

And now u can click, and wait for the magic to happen(if ur ray is along the y axis)

With the slider u can inspect the sim tick by tick

enjoy ;)
